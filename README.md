# Employee Management System - AWS Cloud Project

## Project Overview

A highly available Employee Management System deployed on AWS using Terraform, Ansible, EC2, RDS, and an Application Load Balancer.

## Architecture

- AWS VPC
- Public and Private Subnets
- Internet Gateway
- NAT Gateway
- Application Load Balancer
- EC2 Application Servers
- Auto Scaling Group
- Amazon RDS MySQL
- Terraform for Infrastructure as Code
- Ansible for Configuration Management
- Git/GitHub for Version Control

## Application

The application provides an Employee Management Dashboard with employee data stored in Amazon RDS MySQL.

## Technologies

- AWS
- Terraform
- Ansible
- Linux
- Apache
- PHP
- MySQL
- Git

## Deployment Flow

Terraform
→ AWS Infrastructure
→ EC2
→ Ansible Configuration
→ PHP Application
→ RDS
→ Application Load Balancer

## High Availability

The application servers are distributed across multiple Availability Zones and accessed through an Application Load Balancer.
